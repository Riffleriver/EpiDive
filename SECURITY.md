# Security policy

EpiDive processes local scientific data and can run with substantial compute resources. Treat input matrices, output directories, environment files, and scheduler templates as untrusted until reviewed.

Do not include private sample data, credentials, internal addresses, or access tokens in public issue reports. Redact logs before sharing them.

Security reports should be sent privately to the project owner. A public security contact has not yet been supplied; until one is added, do not open a public issue containing exploitable details.

Only versions listed in the latest GitHub Release are intended to receive fixes.
